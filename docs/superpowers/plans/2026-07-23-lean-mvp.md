# 飞书 Codex 总裁助理精简 MVP

- 日期：2026-07-23
- 状态：`LOCAL_REVIEW_READY`
- 适用对象：一位总裁、一台专用 Mac mini、一个飞书自建应用

## 目标

交付一个真正可运行的个人助理，而不是通用 Agent 平台：

> 总裁在飞书私聊发任务，Mac mini 上的 Codex 处理任务，并把文字或文件结果回复到原私聊；需要修改飞书数据或通知他人时，先展示预览并由总裁确认。

## 本计划取代什么

本计划取代原路线图中尚未执行的 Stage B / Tasks 7–10、Stage C / Tasks 1–9 和 Stage D / Tasks 1–9 的逐任务实施方式。

已经本地提交的 Stage A 和 Stage B / Tasks 1–6 不删除、不返工，作为可复用底座。旧计划继续保留为历史设计和测试参考，但不再决定 MVP 的工作拆分。

## 第一版只交付四件事

### 1. 私聊执行闭环

- 只接受已配置总裁的飞书私聊。
- 事件先进入 SQLite，再回复“收到”。
- 单并发调用专用 `CODEX_HOME` 中的 Codex。
- 保留飞书会话与 Codex session 映射。
- 将最终文字和当前任务生成的文件回复到原私聊。
- 进程中断后不静默重复正在执行的任务。
- “停一下”“停止当前任务”“取消这个任务”能停止当前 run。

### 2. 最小飞书工作能力

首版固定为：

- `minutes.search`
- `minutes.detail`
- `contact.search`
- `message.send`：仅单个接收人
- `calendar.create`：仅单次日程，时区固定为 `Asia/Shanghai`

读取能力可以直接执行。`message.send` 和 `calendar.create` 必须先生成不可变预览，再通过同一总裁私聊中的确认入口执行一次。超时或回执不确定时保持 `UNKNOWN`，不自动重发。

暂不实现：

- 批量广播和新建群
- 重复日程
- 日程更新和取消
- 以总裁本人身份发送
- 通讯录别名库
- 通用 capability 平台或 policy DSL

### 3. PPT 复用

- 安装锁定版本的 `banqiusheng/visual-first-ppt`。
- `executive-assistant` Skill 对 PPT 请求直接委托 `$visual-first-ppt`。
- 不复制 PPT 路由、状态机、QA 或生成逻辑。
- 默认把预览、PPTX 和 PDF 作为任务结果回传；能力缺失时准确报告。

### 4. 傻瓜安装与常驻

- 一个中文安装入口。
- 一个只读 `doctor`。
- 一个用户级 LaunchAgent，使用 `RunAtLoad + KeepAlive` 托管单一 runtime。
- 一个重启入口。
- Secret 只进入 macOS Keychain，不进入仓库、配置、命令参数或日志。
- 安装脚本不修改 FileVault、整机睡眠、Apple ID、备份或系统升级。

## 保留的安全底线

- 只服务一位已配置总裁，群聊和其他用户不能触发 Codex。
- Codex 环境不包含 App Secret、OAuth Token 或原始 `lark-cli`。
- 对外写操作先预览再确认。
- 任务目录限制为 `0700`，任务文件限制为 `0600`。
- 日志不记录客户正文、Secret、Token 或完整人员 ID。
- 真实飞书结果只能通过目标租户测试确认，离线 fake 不写成生产 `PASS`。

## 不再扩展的设计

- 多租户或多 BOSS
- 管理后台、SaaS 控制台
- 通用动作编排平台
- 新的多层 native 身份证明
- 为每项能力单独建立复杂状态机
- 三套 LaunchAgent 和独立 watchdog
- 为理论同 uid 恶意进程继续递归加固

## 完成定义

本地代码进入 `REVIEW` 需要：

1. 离线集成测试证明：飞书消息 → SQLite 任务 → fake Codex → 最终回复。
2. 最小飞书能力的严格 payload、固定身份、预览确认和 `UNKNOWN` 测试通过。
3. 安装、doctor、restart 和 LaunchAgent 静态验证通过。
4. `executive-assistant` 明确委托 `$visual-first-ppt`。
5. 全仓 format、lint、test、typecheck、build 和 `git diff --check` 通过。

生产 `PASS` 仍需要客户 Mac mini 上的：

1. 真实 App ID / App Secret 配置。
2. 总裁真实私聊收发。
3. 真实妙记读取。
4. 经确认创建一条测试日程。
5. 经确认通知一位已同意的测试用户。
6. 真实 PPT 生成与文件回传。
7. 杀进程后 LaunchAgent 自动拉起。
